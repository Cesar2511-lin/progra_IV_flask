# Lightweight Python REST API with Flask 🐍

A modular, lightweight RESTful API boilerplate developed in Python using Flask, structured for endpoint testing and microservice integration.

---

## 🚀 Features
- **Clean Routing**: Modular route structure handling HTTP GET, POST, and JSON payloads.
- **Automated Validation**: Input sanitization and standard HTTP response status handling.
- **Ready for Deployment**: Easily runnable locally or packageable into lightweight Docker containers.

## 🛠️ Usage
```bash
python -m venv venv
# On Windows:
venv\Scripts\activate
pip install flask
python app.py
```
